# Summarization And Persistent Memory

پیاده‌سازی حافظه خلاصه‌ساز و ذخیره‌سازی پایدار برای مدیریت مکالمات طولانی.

## Scripts & Notebooks
- [`01_summary_memory.ipynb`](./01_summary_memory.ipynb): پیاده‌سازی حافظه خلاصه‌ساز (Summary Memory) با زنجیره دوقلو (مدل خلاصه‌ساز + مدل اصلی) و استریمینگ پاسخ.
- [`02_persistent_memory.ipynb`](./02_persistent_memory.ipynb): پیاده‌سازی حافظه پایدار (Persistent Memory) با ذخیره روی فایل JSON (`FileChatMessageHistory`) و آشنایی با معماری دیتابیس‌های حرفه‌ای (Redis، PostgreSQL، MongoDB).
