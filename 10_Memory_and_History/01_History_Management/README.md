# History Management

مدیریت تاریخچه مکالمات و نگهداری زمینه (Context) در LangChain.

## Scripts & Notebooks
- [`01_chat_history.ipynb`](./01_chat_history.ipynb): پیاده‌سازی پایه نگهداری تاریخچه گفتگو با `ChatMessageHistory` و ساخت چت‌بات چندمرحله‌ای به همراه استریمینگ.
- [`02_runnable_with_message_history.ipynb`](./02_runnable_with_message_history.ipynb): مدیریت خودکار تاریخچه با `RunnableWithMessageHistory`، تفکیک کاربران هم‌زمان با `session_id` و پیاده‌سازی سیستم چندچتی مشابه ChatGPT.
- [`03_trim_messages.ipynb`](./03_trim_messages.ipynb): هرس پیام‌ها با `trim_messages` برای مدیریت سقف Context Window و کاهش هزینه توکن همراه با استریمینگ.
