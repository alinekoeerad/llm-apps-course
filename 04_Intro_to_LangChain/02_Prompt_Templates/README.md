# Prompt Templates 📝

In this section, we transition from raw string formatting (like Python f-strings) to using professional `ChatPromptTemplate` in LangChain. 
Templates allow us to build scalable, dynamic, and reusable AI applications.

## 📝 Notebooks

1. **[01_prompt_templates.ipynb](./01_prompt_templates.ipynb)**
   - Creating dynamic system and human messages using `.from_messages()`.
   - Understanding the two-step process: `Template -> Messages -> Model`.
   - Building a dynamic persona (e.g., Humorous Math Teacher).
   - Reusing templates efficiently (e.g., A multi-language translator).
