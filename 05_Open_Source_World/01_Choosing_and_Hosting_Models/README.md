# Choosing And Hosting Models 🤖

In this section, we explore how to choose, host, and run open-source language models locally.

Topics covered:
- Understanding open-source model hosting.
- Model weights, inference code, and tokenizers.
- Loading models manually using Hugging Face Transformers.
- Running local inference with open-source models.

## 📝 Notebooks

1. **[01_self_hosting_with_transformers.ipynb](./manual_transformers/01_self_hosting_with_transformers.ipynb)**
   - Loading an open-source language model using Hugging Face Transformers.
   - Understanding the role of model weights and tokenizers.
   - Running text generation with `AutoModelForCausalLM`.
   - Performing local inference without using external LLM APIs.
